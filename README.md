## Setup in 5 minutes

1. Open a new issue from the **Message board** template and pin it. If it's the first issue in the repo it's #1 and you can skip the next step.
2. If it isn't issue #1, every teammate sets `export BOARD_ISSUE=<number>`.
3. Fill in your team's GitHub logins and the owner table in `AGENTS.md`.
4. Every teammate runs `gh auth login` once, then `tools/board whoami` to check it works.
